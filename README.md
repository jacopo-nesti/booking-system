# BOOKING SYSTEM

---

## Short project description

Web application for managing appointment bookings for a barber shop using Flask and SQLite.

---

## Features (MVP)

- booking creation
- treatment selection
- time slot validation
- admin dashboard
- email confirmation

---

## Tech stack

- Python
- Flask
- SQLite
- HTML / CSS / JavaScript
