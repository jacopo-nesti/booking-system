# BOOKING SYSTEM

---

## Short project description

Web application for managing appointment bookings for a barber shop using Flask and SQLite.

---

## Features (MVP)

- booking creation (done!)
- treatment selection (done!)
- time slot validation (done!)
- admin dashboard (work in progress)
- email confirmation (work in progress)

---

## Tech stack

- Python
- Flask
- SQLite
- HTML / CSS / JavaScript
